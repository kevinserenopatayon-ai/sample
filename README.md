# Kevin & Joana — Wedding Fellowship

A page-by-page wedding invitation designed for GitHub Pages.

## Pages

1. Welcome
2. Invitation
3. What to Wear
4. RSVP / Gifts
5. Venue
6. Closing message

## Features

- One full-screen page at a time
- CSS scroll snap
- Mouse-wheel page-by-page navigation
- Touch/swipe navigation
- Keyboard navigation
- Smooth page transitions
- Scroll reveal animations
- Elegant cream and gold design
- Responsive on desktop, tablet, and mobile
- The four supplied artwork pages are included in `assets/`

## GitHub Pages setup

1. Create a new GitHub repository.
2. Upload:
   - `index.html`
   - `style.css`
   - `script.js`
   - the entire `assets` folder
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Save and wait for GitHub Pages to publish.

The site entry point is `index.html`.
